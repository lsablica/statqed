# Registry v0 schema

Status: Experimental and test-only.

`registry-record-v0.cddl` expresses the closed structural shape of the single
SQ-0007 record with published RFC 8610 CDDL syntax.  CDDL acceptance is only a
structural result.  It does not establish canonical bytes, Lean proposition or
environment identity, authorization, proof trust, source fidelity, or
statistical validity.

Field meaning, canonical byte rules, lock separation, stable errors, and
resource bounds are governed by the Accepted RFC-0005 decision scope and the
versioned documents under `theorem-registry/spec/`.
