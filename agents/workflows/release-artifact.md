# Workflow: Release a StatQED Artifact or Software Version

1. Freeze schema, theorem, method-pack, and toolchain locks.
2. Build from a clean, documented environment.
3. Run all required tests and independent verification modes.
4. Generate checksums, provenance, citation files, SBOM, and source archives.
5. Verify offline archival instructions.
6. Review migrations and historical artifact compatibility.
7. Publish known limitations and security status.
8. Tag only after release review; never retag immutable releases.
9. Deposit archival material and record persistent identifiers when available.
