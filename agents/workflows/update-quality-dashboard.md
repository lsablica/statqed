# Workflow: Update the Quality Dashboard

1. Identify claims whose evidence changed.
2. Link evidence to commits, test outputs, review records, statement hashes, and artifact digests.
3. Update counts only from machine-readable ledgers or reproducible commands.
4. Preserve known limitations and failed experiments.
5. Separate planned, implemented, reviewed, Candidate, and Stable states.
6. Have an integrator check that dashboard language cannot be read as a broader verification claim.

The dashboard is evidence reporting, not marketing copy.
