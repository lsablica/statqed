# Test Strategy

Test layers:

- unit and theorem examples;
- property and metamorphic tests;
- finite exhaustive models;
- differential cross-language tests;
- canonical byte/digest vectors;
- malformed/security/resource tests;
- corrupted certificate tests;
- assumption ablations and theorem mutations;
- overclaim/report-language tests;
- clean-checkout and archival verification.

The oracle must be independent where practical. Golden vectors are reviewed semantic artifacts, not snapshots accepted because code emitted them.
