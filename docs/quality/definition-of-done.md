# Definition of Done

A task is done only when its observable outcome, tests, reviews, documentation, status, and handoff are complete.

A public theorem additionally needs source audit, frozen statement hash, non-vacuity example, material ablation tests, randomness/quantifier review, axiom report, registry entry, and interpretation/nonclaims.

A checker additionally needs exact proposition, bound inputs, malformed/resource behavior, independent oracle, corruption tests, and soundness theorem/obligation.

A method pack additionally needs frontends, artifact, provenance, citations, trust report, performance, and an end-to-end exemplar.

Compilation alone is never the definition of done.
