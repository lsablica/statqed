# Known Limitations

At scaffold time:

- no Lean/Rust/frontend toolchain is initialized;
- no normative schema is accepted;
- no theorem is registered;
- no certificate checker exists;
- no `.statqed` artifact is verified;
- no empirical assumption can be established;
- package names and toolchain pins remain provisional;
- the proposed TCB and encoding require RFC review;
- the agent system has not yet been experimentally evaluated.

These limitations are intentional. They prevent architecture documents from being mistaken for functioning assurance software.
