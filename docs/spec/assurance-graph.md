# Statistical Assurance Graph Specification

Status: **Draft 0**.

The assurance graph is a typed DAG.

## Initial node kinds

- claim;
- theorem application;
- numeric fact;
- data-derived fact;
- transformation;
- external assumption;
- attestation;
- diagnostic;
- citation;
- provenance entity/activity/agent;
- unresolved obligation.

## Edge kinds

- deductive dependency;
- checker establishes fact;
- theorem instantiation;
- derived from data;
- attests to assumption;
- diagnostic informs judgment;
- generated by activity;
- attributed to source;
- incompatible with;
- refines or weakens.

The type system forbids a diagnostic-to-assumption deductive edge unless a registered theorem explicitly supplies it. Cycles are invalid. Every reportable conclusion resolves to its dependency closure and exposes unresolved/external leaves.
