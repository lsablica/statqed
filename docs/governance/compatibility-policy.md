# Compatibility Policy

Compatibility is assessed separately for source API, IR, artifact bytes, theorem meaning, method packs, adapters, and verifier behavior.

A reader may accept an old artifact only under an archived verifier or an explicit migration. Theorem replacement requires identical statement hash or a registered implication in the needed direction. Lossy migrations produce a new artifact and disclosure.

Deprecations name successor, rationale, earliest removal, and historical-verification path.
