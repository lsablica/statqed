# Maturity Model

Status: **Draft**.

**Draft:** design or source work incomplete.

**Experimental:** implemented end to end; interfaces and claims may change.

**Candidate:** semantics frozen and independently reviewed; compatibility window begins.

**Stable:** versioned, conformance-tested, archived, migration-governed, and security-supported.

**Archived:** retained for historical verification, not active development.

Maturity applies per component and theorem, not automatically to the whole repository.
