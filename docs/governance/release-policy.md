# Release Policy

## Pre-alpha

No stability or verification claims. Interfaces may change.

## Experimental release

Executable vertical slice, complete limitation statement, reproducible source/build, and no trusted-path placeholders.

## Candidate release

Semantics/statement locks frozen, independent reviews complete, conformance vectors and migration draft published.

## Stable release

Versioned specs, reproducible/archival verifier, independent implementation or audit evidence, compatibility policy, security support, citation archive, and governance approval.

Tags are immutable. Releases pin Lean, Mathlib, Rust, schemas, registry, packs, adapters, checksums, and accepted axiom baseline.
