# Naming and Package Layout

The academic project name is **StatQED**. Provisional package names:

- R: `statqed`;
- Python: `statqed`;
- Julia: `StatQED.jl`;
- CLI: `statqed`;
- artifact extension: `.statqed`;
- Lean namespace/library: `StatQED`.

SQ-0001 must verify registry/name availability and trademark/confusion risks before acceptance. Internal modules may use names derived from StatQED (`StatCore`, `StatIR`, `StatCert`, `StatQEDBench`) only when their ownership and public citation relationship remain clear.
