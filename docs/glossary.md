# Glossary

**Assurance artifact:** portable bundle recording claims, dependencies, evidence, certificates, provenance, and verifier locks.

**Assurance graph:** typed DAG whose edges state valid dependency relations among claims, assumptions, computations, data facts, diagnostics, attestations, and provenance.

**Certificate producer:** untrusted program that emits a candidate result and witness.

**Checker:** small deterministic program whose acceptance is linked by theorem to a precise proposition.

**Claim:** typed proposition intended to support a reportable conclusion.

**Data commitment:** digest binding an artifact to a canonical logical dataset or declared data reference.

**Diagnostic:** computed evidence that may inform scientific judgment but does not automatically establish a model assumption.

**Estimand:** target functional or quantity of scientific interest, distinct from estimator and fitted coefficient.

**Evidence:** typed support such as kernel proof, checked computation, data-derived fact, attestation, diagnostic, citation, or unresolved obligation.

**External assumption:** premise about the physical/scientific world that is not established merely by formal verification of code or data.

**Identification:** relation connecting a scientific estimand to observable-data quantities under assumptions.

**Method pack:** end-to-end package of semantics, theorems, witnesses, checkers, producers, frontends, tests, provenance, and citations.

**Randomness scope:** named source of probability, such as assignment, sampling, resampling, algorithmic, or posterior randomness.

**Statement hash:** digest of a normalized public theorem statement, independent of proof body.

**Theorem lock:** exact proof-backend, library, declaration, statement-hash, and method-pack versions used by an artifact.
