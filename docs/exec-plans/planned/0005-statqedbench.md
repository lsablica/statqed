# Planned Plan 0005: StatQEDBench

## Goal

Create the canonical source-aligned benchmark for formal statistical reasoning and proof-carrying analysis.

Task families include statement formalization, assumption extraction, randomness-scope identification, estimand extraction, hypothesis-laundering detection, counterexamples, theorem retrieval, source-language lowering, numerical witness generation, corruption detection, and overclaim review.

Every item records source/license, target semantics, scoring, failure taxonomy, contamination risk, and review. Maintain public development, public test, and untouched hidden evaluation splits. Benchmark releases are versioned and never silently rewritten.
