# Planned Plan 0006: Causal Identification

## Goal

Represent and formally connect scientific causal estimands, identification assumptions, observed-data functionals, estimators, inferential guarantees, numerical results, and interpretations.

Initial scope: randomized-treatment identification, consistency/SUTVA components, positivity, back-door adjustment in a finite/discrete setting, partial identification, and sensitivity evidence.

The plan must prevent a regression coefficient or well-computed estimator from being presented as a causal effect without an identification theorem and visible external premises.
