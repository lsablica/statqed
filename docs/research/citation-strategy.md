# Citation and Academic Adoption Strategy

The project should create reusable dependencies rather than fragmenting publications.

## Canonical assets

- one foundational semantics/assurance-graph paper;
- one core library/registry/verifier paper;
- one numerical-certificate paper;
- one StatQEDBench/agent-methodology paper;
- domain method-pack papers.

Artifacts generate citations for the StatQED core, exact method packs, original mathematical sources, software release, data, and adapters. Original-source attribution is mandatory.

Track external imports, method packs, artifacts in papers, benchmark submissions, independent verifiers, Mathlib contributions, courses, and textbooks. High citation counts are a long-term consequence of central, open, reliable infrastructure.
