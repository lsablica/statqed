# StatQEDBench Research Design

The benchmark should measure semantic fidelity rather than syntax completion.

Metrics include exact target match, hypothesis support, quantifier/randomness correctness, non-vacuity, theorem applicability, certificate validity, conformance, and overclaim rate. Evaluation reports failure classes separately.

Hidden splits must include source works, theorem variants, software versions, and methods not represented in the public development set. Contamination audits and retrieval baselines are mandatory.
