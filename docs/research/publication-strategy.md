# Academic Publication Strategy

Central citable outputs:

1. proof-carrying statistical analysis semantics and assurance graph;
2. StatQED core library, registry, and verifier;
3. numerical certificate architecture;
4. StatQEDBench and agent-workflow evaluation;
5. domain method papers for randomization, linear models, conformal/sequential, causal identification, and later towers.

Use one canonical core project citation while preserving original theorem citations and method-pack contributor credit. Aim for dependency and reproducible artifact adoption; citation counts are a consequence, not a direct quality metric.
