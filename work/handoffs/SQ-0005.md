## Selected profile

`statqed.cbor-core.v1` selects RFC 8949 core deterministic encoding with
complete encoded-key byte ordering, preferred heads, and definite lengths.
Accepted values are direct-range integers, bytes, exact Unicode scalar text,
arrays, narrow-key maps, booleans, and null. Tags, floats, bignums, rationals,
decimals, intervals, extensions, indefinite forms, nonpreferred heads,
duplicate keys, and silent normalization are rejected or explicitly
unsupported. Unicode is preserved and is not normalized.

The profile fixes 1 MiB input/output, 64 KiB string, 1,024 collection, 4,096
total-item, depth-32, and 4,096-byte diagnostic limits. Every failure belongs
to a stable staged result class; CDDL structure, deterministic bytes, semantic
validity, digest verification, schema validation, provenance, and statistical
validity are not collapsed.
