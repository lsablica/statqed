## Deterministic CLI contract and malformed-input results

The only successful surface is `statqed --version` and
`statqed version --format text|json`. The protocol-v1 JSON error surface handles
malformed or unsupported invocation, writes only stderr, and exits 2. Stable
codes cover missing/unknown/repeated/empty/invalid/unexpected input, invalid
Unix argument encoding, and resource limits. Broken output returns exit 1.

No response contains rejected input, timestamps, random IDs, host paths,
locale-dependent text, dependency debug strings, stack traces, or panics.
Limits are 64 arguments, 4,096 bytes per argument, and 8,192 aggregate bytes;
both sides are permanently tested under both toolchains. The fixture digest is
`41a8675a17c8e8fba799cb9811e2dc90170d30eb20d377c35c15d892b48a8927`.

Tests cover the required no/missing/unknown/repeated/empty/truncated/long,
non-UTF-8, randomized, aggregate-boundary, and broken-output cases. The
independent security review additionally exercised 8,433 cases.

## Update, rollback, and generated-file policy

An update requires current official-source and advisory research; independent
testing of the new development/floor pair; Cargo 1.97.1-or-successor lock
generation in clean credential-free homes; regeneration of all evidence;
development and offline-floor gates; every mutation; hosted CI; and distinct
Rust, source, security, CI, and integration review. Never auto-promote a
floating toolchain or dependency result.

Rollback atomically restores the toolchain, manifests, lock, sources,
workflow, evidence, and documentation to one reviewed commit, then repeats its
exact checks. Partial rollback must fail its bindings. Build targets, Cargo
homes, extracted advisory inputs, actionlint, and temporary worktrees are
disposable. Cargo generates `Cargo.lock`; the documented Python tools generate
the normalized evidence. Hand editing generated results is prohibited.
