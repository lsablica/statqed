# Requests for Comments

RFCs govern constitutional and semantic decisions. Use `agents/templates/rfc.md` and `docs/governance/rfc-process.md`.

Initial expected RFCs:

- deterministic encoding/canonicalization;
- core evidence and assurance taxonomy;
- Lean artifact decoder/bridge trust boundary;
- core statistical ontology and probability context;
- theorem identity, proof trust, and compatibility;
- canonical logical data digest;
- cross-component compatibility and migration;
- deterministic artifact envelope and offline resolution;
- community membership, voting, conflicts, and succession;
- public method-pack extension protocol.
